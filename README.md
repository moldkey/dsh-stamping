<p align="center"><strong>dsh-stamping — 冲压力与冲压 DFM</strong></p>

冲裁力/吨位估算，最小孔径与边距/折弯检查。

## 安装

    dsh plugin --profile web add github:moldkey/dsh-stamping

## 工具

- `stamping_force`：冲裁力与压力机吨位
- `stamping_dfm`：冲压 DFM

更多工具：https://deepseekbase.com/zh/tools/
